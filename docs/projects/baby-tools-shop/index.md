# Baby Tools Shop

A full-stack e-commerce application for baby products, developed with **Python and Django**.

## Overview

The project demonstrates the development and deployment of a modular web application, including user authentication, product management, database integration, testing, and containerization.

## Technologies

- Python
- Django
- Docker
- PostgreSQL
- GitLab CI/CD
- pytest

## Key Areas

- Full-stack web application development
- Database and application architecture
- Authentication and user management
- Automated testing
- Code quality and linting
- Containerization
- CI/CD

## Goal

The project was developed as a practical exercise in building, testing, containerizing, and deploying a modern Python web application.
