A customizable documentation website built with [Docusaurus](https://docusaurus.io/), React, and TypeScript.

Docusaurus is a modern static-site framework designed for documentation, but it can also be adapted for developer portals, knowledge bases, technical blogs, project websites, tutorials, product documentation, and personal websites.

This repository demonstrates how Docusaurus can be extended with custom React components, TypeScript configuration, custom styling, structured documentation, and automated deployment.

## Overview

Docusaurus combines Markdown/MDX content with React and static-site generation.

It provides a structured environment for creating and maintaining documentation while allowing developers to customize the website using standard web technologies.

Typical use cases include:

- Technical documentation
- Developer documentation
- API documentation
- Project documentation
- Knowledge bases
- Tutorials and guides
- Internal engineering documentation
- Open-source project documentation
- Technical blogs
- Product documentation
- Learning resources
- Personal websites and portfolios

Not every capability or use case listed above is implemented in this repository. They represent the broader capabilities of the Docusaurus platform.

## Capabilities

Docusaurus provides a broad set of features for building documentation-focused websites.

### Documentation

- Markdown and MDX
- Documentation versioning
- Multiple documentation sections
- Automatic sidebar generation
- Custom sidebars
- Categories and document organization
- Code syntax highlighting
- Search integration

### Website Customization

- React components
- TypeScript support
- Custom React pages
- Custom CSS
- Theme customization
- Responsive layouts
- Dark and light themes

### Platform Features

- Static-site generation
- SEO-friendly pages
- Internationalization
- Blog functionality
- Plugin ecosystem
- Custom plugins and integrations
- GitHub integration
- Static hosting
- GitHub Pages deployment
- CI/CD integration

Docusaurus is designed to provide a documentation-first architecture while still allowing developers to build highly customized websites.

## Repository Implementation

This repository uses Docusaurus with the Classic preset and extends the default implementation with custom React components, TypeScript configuration, CSS, documentation structure, and deployment configuration.

### Documentation

Documentation is stored in the `docs/` directory.

The project uses Docusaurus's autogenerated sidebar functionality to derive navigation from the documentation structure.

Documents can be organized into categories using Docusaurus category metadata.
