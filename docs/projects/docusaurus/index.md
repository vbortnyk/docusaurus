# Docusaurus

A personal DevSecOps portfolio built with Docusaurus, React and TypeScript and deployed to GitHub Pages.

The project demonstrates documentation engineering, frontend customization and automated deployment using GitHub Actions.

## Project Overview

The website is built with Docusaurus and customized using React, TypeScript and CSS.

It serves as a technical portfolio for documenting DevOps and DevSecOps projects, infrastructure configurations and security-related writeups.

The project includes:

- Custom Docusaurus configuration
- React components for portfolio sections
- TypeScript-based configuration and components
- Custom CSS styling
- Project documentation with Markdown
- Automatically generated documentation sidebar
- GitHub Pages deployment
- GitHub Actions CI/CD
- Environment-based configuration
- GitHub Secrets for sensitive configuration

## Documentation

The documentation is organized into project-specific sections.

Each project contains an overview and technical writeups covering implementation details, configuration and DevOps concepts.

## CI/CD

The website is deployed automatically using GitHub Actions.

The deployment pipeline builds the Docusaurus application and publishes the generated static website to GitHub Pages.

Environment-specific values can be provided through GitHub Actions environment variables and GitHub Secrets rather than being hardcoded into the project.

## Customization

The default Docusaurus interface has been customized to create a personal portfolio experience.

Customizations include:

- Portfolio project cards
- Custom navigation
- Custom branding and logo
- Responsive project layouts
- Custom typography
- Custom CSS
- Technology tags and icons
- Project-specific documentation
- Dark/light color mode support
