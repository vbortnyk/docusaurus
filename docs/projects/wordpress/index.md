# WordPress

A containerized WordPress deployment using Docker Compose and MariaDB.

This project demonstrates practical containerization and DevOps concepts, including Docker Compose, MariaDB, persistent storage, environment-based configuration, container networking and automated container initialization.

## Project Overview

The deployment consists of two main services:

- **WordPress** — web application running on Apache and PHP
- **MariaDB** — relational database used by WordPress

Docker Compose manages both services and provides networking between them.

## Technologies

| Technology | Purpose |
|---|---|
| WordPress | Web application |
| PHP | WordPress runtime |
| Apache | Web server |
| MariaDB | Relational database |
| Docker | Containerization |
| Docker Compose | Multi-container orchestration |
| Shell | Automation and container initialization |
