# V-Server Setup

A practical guide for securely configuring SSH access to a virtual server.

## Overview

This project demonstrates how to secure SSH access by using **SSH key-based authentication** instead of passwords.

## Key Topics

- SSH key generation
- Key-based authentication
- Secure remote access
- Disabling password authentication
- SSH configuration verification

## Goal

Establish a secure and reliable method for remote server administration while reducing the risks of password-based SSH access.
